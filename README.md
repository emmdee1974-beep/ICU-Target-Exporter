# ICU — I See You Target Exporter

ICU is a lightweight Torn userscript that copies visible faction member XIDs into a clean comma-separated list for easy YATA importing.

Built for faster ranked war preparation and target collection.

## Features

- Copy visible faction member XIDs
- Comma-separated export format
- Save and automatically ignore your own XID
- No Torn API required
- Collapsible/minimized interface
- Lightweight floating UI
- Small clickable bear icon linking to LoneBlackBear [3163918]

## Installation

Install using:
- Tampermonkey
- Violentmonkey

Then install the `.user.js` script.
